# タイトル

ウィンドウ消し

# 概要

画面に表示されたウィンドウを時間内に消すゲーム

# 操作方法

マウス操作とクリック入力でウィンドウを消していく

# 使用技術

VisualStudio2022
          C++ DxLib

# 製作期間

約六か月

# 工夫した点

難易度の調整ができるようにウィンドウの数をプレイヤーが調整できるようにしました

# 今後の改善点

メインゲームがシンプルすぎるので他に追加の要素・操作を増やしたい
基本プレイがマウスなのにスタートや設定がキーボード操作なのでどちらかに統一するべきだった
